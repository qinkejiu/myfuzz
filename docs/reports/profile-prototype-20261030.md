## riscv-dv 程序复现

在隔离 Python 3.12 环境安装 `pyvsc==1.0.0 bitstring==3.1.9 PyYAML==6.0.3 tabulate==0.10.0`；源码锁定 revision `71666ebacd69266b1abb7cdbad5e1897ce5884e6`。在工作目录创建内容为 `from importlib import reload` 的 `imp.py`，设置 `PYTHONPATH` 包含该工作目录及仓库 `third_party/rfuzz/upstream/ibex/vendor/google_riscv-dv/pygen`，然后运行：

```sh
python "$DV/pygen/pygen_src/test/riscv_instr_base_test.py" \
  --target=rv32i --num_of_tests=1 --start_idx=0 --asm_file_name="$OUT/test" \
  --log_file_name="$OUT/gen.log" --gen_test=riscv_instr_base_test --seed=1 \
  --instr_cnt=20 --num_of_sub_program=0 --no_branch_jump=1 \
  --no_load_store=1 --no_csr_instr=1 --no_data_page=1
clang --target=riscv32-unknown-elf -march=rv32i_zicsr_zifencei -mabi=ilp32 \
  -nostdlib -fuse-ld=lld -Wl,--build-id=none -Wl,-T,"$OUT/boot.ld" \
  -I"$DV/user_extension" "$OUT/test_0.S" -Wl,--oformat=binary -o "$OUT/test.bin"
```

`DV` 是上述 vendored riscv-dv 的绝对目录，`OUT` 是新工作目录；`boot.ld` 来自其 `scripts/link.ld`，将入口 `0x80000000` 改为本 CPU 的实际首取指地址 `0x10000`。此处的限制只控制随机部分，并不禁止启动/结束代码访问 CSR 或栈。生成 binary SHA256 `44bcebd9012a6614e17a033bd73767bb65cbe80fbe1e7f7068d4958373cf6b53`。
