# PULP APB timer storage-probe hierarchy proof

## Result

The registered storage probe for `configs/scenarios/compiled-f4-obi-apb-timer`
is **bound to a live elaborated signal**.  No expression/path fix was needed:

```
u_component.u_dut.TIMER_GEN[0].timer_i.regs_q[1]
```

- `u_component` is the generated `local_peripheral` wrapper instance in
  `runtime.sv` (`local_runtime_peripheral`).
- `u_dut` is the `apb_timer` instance in the generated wrapper.
- `TIMER_GEN[0]` is the `generate for` block instance selected by Verilator.
- `timer_i` is the `timer` instance inside that block (`apb_timer.sv:71`).
- `regs_q[1]` is the `TIMER0_CTRL` word of `timer.sv:47` (`REG_TIMER_CTRL=1`).

Verilator 5.051 resolves this dotted generate path.  An out-of-range index
(`TIMER_GEN[9]`), an unknown instance (`timer_x`) or an unknown variable
(`regs_x`) each makes elaboration fail; the probe is not accepted from the
Python expression string alone.

## Elaboration and native sample evidence

Generator input: the committed scenario config, D2 generation only via
`prepare_compiled_execution_files` (the generated `runtime.sv`/`wrapper.sv`
are byte-identical to the I3 run: runtime `3ec91be8…`, wrapper `7bffa340…`).

Verilator lint (`--lint-only --top-module local_runtime_peripheral`) exits 0.
Three mutated runtimes containing an unbound expression all exit 1 with a
Verilator `Can't find definition` resolution error (an unrelated lint failure
does not count as a refused control):

| negative control | mutation | result |
|---|---|---|
| out-of-range generate index | `TIMER_GEN[9]` | refused, exit 1 |
| unknown instance | `timer_x` | refused, exit 1 |
| unknown variable | `regs_x[1]` | refused, exit 1 |

A native C++ model was built from the exact generated bytes and the ten
`storage_*` top ports were sampled every cycle.  Observed behavior:

| cycle | event | `storage_value` | `storage_paddr` | `pwrite` | `storage_pwdata` | `storage_prdata` |
|---|---|---|---|---|---|---|
| 1–3 | reset asserted | `0x00000000` | 0 | 0 | 0 | 0 |
| 5–6 | write timer 1 CTRL `0x14` = `0x5a5a5a5a` | `0x00000000` | `0x014` | 1 | `0x5a5a5a5a` | 0 |
| 9–10 | write timer 0 CTRL `0x04` = `0xa5c30001` | `0x00000000` | `0x004` | 1 | `0xa5c30001` | 0 |
| 11 | post-write commit | `0xa5c30001` | 0 | 0 | 0 | 0 |
| 13–14 | read timer 0 CTRL `0x04` | `0xa5c30001` | `0x004` | 0 | 0 | `0xa5c30001` |
| 17–18 | second write `0x04` = `0x13572468` | `0xa5c30001` | `0x004` | 1 | `0x13572468` | 0 |
| 19 | post-write commit | `0x13572468` | 0 | 0 | 0 | 0 |
| 21–22 | read `0x04` | `0x13572468` | `0x004` | 0 | 0 | `0x13572468` |

The timer-1 write deliberately does **not** move `storage_value`, proving the
probe is bound to `TIMER_GEN[0]` rather than the other generate instance.
`storage_reset` follows the runtime reset (1 during reset, 0 after),
`storage_psel`/`storage_penable` pulse during APB SETUP/ACCESS,
`storage_pready` reads 1 and `storage_pslverr` reads 0 (the timer RTL drives
these constants); the other eight ports show real transitions.  All ten ports
are read directly from the Verilated top-level model.

Proof digest: `a889c6eb699ecdbd2ad4959f3ca14a5762608edb5a8ce93523343e02fffbef85`
(`proof.json`).  Probe binding digest:
`fc2056da3f3857290b8e06428d32939229be3788544d7fe9eede32bea83117a3`.

## How the flags become true

The flags are not constants that were flipped.  The new module
`src/myfuzz/local_harness/apb_storage_probe_verification.py` validates the
committed proof against:

- the exact probe ports (names, widths, expressions),
- the reviewed source-contract digest, source bytes and parameters,
- the exact generated runtime SV bytes and wrapper bytes,
- non-empty live samples, reset-zero and write/read-access invariants,
- three refused unbound-expression negative controls.

`_render_admitted_runtime` calls `attach_native_proof` after rendering the
runtime.  Only if every binding matches does the observation become
`hierarchy_verified=true` / `native_verified=true` and gain a
`hierarchy_evidence` reference.  A missing, stale or tampered proof leaves the
prospective flags false; a claimed-verified observation is refused unless the
evidence validates.  `reset_authority`, `version_authority` and
`source_authority` remain false, and the documentary source contract keeps its
prospective status.

The generic producer binding now records the observation flags and evidence in
its `probe` block.  The consumer (`check_storage_observation`) still requires
the four receipt joins; it accepts a verified observation only through the same
digest-bound evidence check.  Probe selection and the joins were not weakened.

## Reproduction

```bash
# bounded D2 generation + Verilator elaboration + one native build/sample run
PYTHONPATH=src:. python3 scripts/verify_apb_storage_probe.py

# pure proof plumbing + probe generation tests
PYTHONPATH=src:. python3 -m pytest \
  tests/local_harness/test_apb_storage_probe_verification.py \
  tests/local_harness/test_apb_storage_probe_generation.py -q

# opt-in native pytest (takes the heavy-worker lock; may skip if busy)
MYFUZZ_NATIVE_VERILATOR=1 PYTHONPATH=src:. python3 -m pytest \
  tests/local_harness/test_apb_storage_probe_verification.py -q -k native
```

`scripts/verify_apb_storage_probe.py` takes
`.superpowers/heavy-worker.lock` with `flock -w 14400`, uses one bounded
native build under `.superpowers/cache-verilog-probe-*`, and writes `proof.json`
only after every check passes.

## Residual uncertainty

- This proves the probe *binding* and live sampling for the timer source
  revision, parameters (`APB_ADDR_WIDTH=12`, `TIMER_CNT=2`), generated wrapper
  and runtime in `proof.json`.  It does not prove full register semantics,
  coverage, or campaign results.
- `pready` and `pslverr` are constant RTL outputs; they are observed constants,
  not transitions.
- The proof records the Verilator build used (`5.051 devel …`).  A different
  toolchain may produce different generated C++ but the SV binding identity is
  the runtime/wrapper/source digests above.
- The source contract remains documentary and prospective by design; the
  verified fact lives in the generated observation's evidence reference.
