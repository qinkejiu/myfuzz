## Required audit adapter — fail closed until supplied

The independent reviewer must provide a new `p8_copy_input_audit.v1` receipt with status `independent_audit_passed`, exact source path and `qualified_map_sha256`; component receipts additionally bind the exact official revision. This interface is a required adapter/join over actual accepted audit evidence, not a claim that existing component receipts already have this shape. Root must review that adapter, including its original actual evidence references, before creating it. The draft does not generate acceptance receipts itself.

A qualified map contains exact `files` and `directories` dictionaries. Each regular row has kind/mode/bytes/SHA256; links additionally have raw-link hex and actual Git blob OID. Existing materializer maps may require a separately audited schema conversion adding official link OIDs, without changing content. `tracked_links` binds Git mode120000/OID/raw-link bytes, checked by canonical blob SHA1; maps/receipt hashes pin the independent full Git qualification of regular blobs/modes. The pure copier runs no Git and cannot independently certify those historical Git facts. Missing receipt/map/link qualifications fail rather than fabricate ready state.

## Plan and prepare

`plan` and `prepare` modes both require selection path/SHA, plan path, new destination and receipt. Plan writes `p8_project_copy_plan.v1` with source typed maps, complete post-overlay map, selection SHA and exact destination. It records only `planned_pending_explicit_prepare`. Explicit prepare additionally requires plan SHA; recomputed inputs/merged map must equal every reviewed plan field. It copies to a new unpublished sibling stage, checks complete maps and metadata, rechecks source inputs, then renames to the new destination. Result is only `copied_pending_independent_audit`; `source_prepared` is a mechanical copy result, not independent audit or runtime acceptance.

Typed census uses lstat/readlink and os.walk without following symlink directories. Only independently qualified tracked symlink leaves are admitted outside metadata; raw target bytes and mode are preserved. Targets must be relative and lexically internal to their component input. Regular-file hashing and copying use O_NOFOLLOW, regular/nlink1 checks and explicit parent-link rejection. Metadata paths reject links, `.promisor`, partialclone/promisor/external config settings, nonempty alternates/commondir and component pointer files. HEAD/config and exact objects/refs/refs-heads/refs-tags directory presence are required for root and every selected component. No object closure is inferred from topology alone.

Maps preserve all selected empty directories/modes, disjoint typed leaves and normalized mount parents. Cross-input leaf collisions or children under file/link leaves fail; only identical parent directory entries can merge. Source-before/source-after and destination maps compare against pinned post-overlay expected maps, including all link bytes and modes. Directory creation precedes link creation. Stage links use os.symlink and receive no chmod/follow operation. Files/metadata are new independent ordinary copies; old component metadata is excluded before qualified stage bytes are overlaid.

The initial draft requires structurally valid inputs before entering its receipt-writing copy scope; early malformed/missing input or output-policy errors therefore fail without a copy-ready receipt.
