## 未声明与边界

- `rvfi_intr`、`rvfi_pc_wdata`、`rvfi_trap`、`rvfi_mode`、`rvfi_mem_*`、`halt` 未观测；debug/NMI/halt 改道在本 profile 为 `unobservable`，不据此声称无改道。
- 没有精确 IRQ↔retirement serial token；F5 的 join 是文档顺序 + PC/insn/order，不是 serial。
- 内部寄存器版本、跨例 writer 归属、IRQ 内部 cause 仍 `unknown`；`grants_F5/F6=false`、`reward_eligible=false`。
- 该结果证明 E40 这一 profile 与既有 DMA/GPIO 的公共执行和证据链复用，不外推到未注册 CPU、RV32E variant 或其他 IRQ IP。
- 时间是两次独立 CLI 的 wall/阶段记录，不是同源性能 A/B；不据此作提速结论。
