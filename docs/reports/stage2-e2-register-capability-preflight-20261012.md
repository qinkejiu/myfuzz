It does not create waiting transactions, materialize RAM, reserve actions or issue commands. `ScenarioSession.configure_register_capability_preflight(...)` installs the opt-in before begin. It computes both report and source identities before publishing state, calls the actual minimum-level gate, and rechecks startup support before commands. After begin, reports retain their startup scope; consumed slots do not invalidate export. Actual requests still require current admission checks. Uncertain schema17 export preserves the startup report and actual terminal evidence without granting further authority.

Fresh replay computes the report from installed actual objects and compares the complete saved report before begin. The CLI returns this fresh report only for enabled bundles.
