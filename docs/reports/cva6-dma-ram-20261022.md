## 实现与证据边界

固定 RV64 CVA6/64 位 AXI 与 ZipCPU Wishbone DMA 使用标准 Runner、
同一 host PersistentMemory。低地址非缓存 RAM 为 0x10000/64KiB，
source/destination/result 为 0x11000/0x12000/0x13000，DMA 控制窗口
0x40002000/16。Host 仅预装代码和零目标／结果，CPU 写源和全部配置。

共享固件增加默认关闭的 ordered_stores，CVA6 显式启用，所有 SW 后
插入真实 FENCE iorw,iorw；原 CVW/Vexii 已执行镜像逐字节保持。
FENCE 排空 store buffer，不代表缓存失效。源／目标读取要求 ARSIZE2，
CPU store 要求 AWSIZE2、AWLEN0、实际 WSTRB0f/f0 与对应 B。原始
内存记录保留八字节和八个 writer/version，仅选定四字节用于固件证明。

[软件 fixture 证据](evidence/cva6-dma-ram-20261022/software-fixture.json)
验证未启动状态、共享内存、高半 lane 路由和排队计数；其中 reset 传输
明确使用 stub，不代表实际复位。[预编译终态](evidence/cva6-dma-ram-20261022/prepare-attempt1/process.json)
为 exit0／86.21 秒、零 native cases。独立静态审查发现并修复了读宽度
和写突发限制两项门禁缺口，最终脚本 SHA 为
`853f30be5c94112048b3dc539c15155228dc9b7371f4845948679a864c615a80`。
独立原生证据审计：[审计报告](../../.superpowers/sdd/cva6-dma-native-audit-20261022.md)，
结论无 Critical、Important、Minor 发现。

此切片不授予 IRQ/ISR、物理共享 SRAM／总线桥、全局时钟、退休、
通用 D4/F6 或 P6/P7/P8 总体完成。
