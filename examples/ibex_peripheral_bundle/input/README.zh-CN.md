# 输入目录说明

本目录严格按自动组合需要的五类事实分组：

1. `01_cpu_interface/`：CPU 的真实端口和顶层模块说明；
2. `02_hdl_source/`：CPU 完整源码集合、版本和编译参数清单；
3. `03_protocol_rules/`：CPU/外设协议字段和握手规则；
4. `04_peripheral_descriptions/`：五种真实外设的模块、协议和源码说明；
5. `05_isa_test/`：RV32IMC、共享内存和本次短测配置。

JSON 链接指向仓库中的权威文件，源码清单指向固定版本的 Ibex 上游源码。这样输入目录
能清楚展示“组合器读取什么”，又不会复制和维护第二份 HDL 源码。
