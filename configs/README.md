# Configs

Design configs live under `configs/designs/`.

```text
configs/designs/smoke/  small local smoke design
configs/designs/ibex/   Ibex default and enhanced instrumentation configs
configs/designs/cva6/   CVA6 default and enhanced instrumentation configs
configs/designs/xiangshan/ XiangShan generated RTL config
configs/designs/boom/   Chipyard SmallBoomV3 BOOM configs
configs/designs/ip_verilog/ Verilog IP branch-only and predicate comparison configs
```

These configs are the canonical inputs for `src/myfuzz/scripts/run_design_flow.py`.
