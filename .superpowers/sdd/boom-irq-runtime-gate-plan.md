# BOOM IRQ runtime gate source plan

Scope: new `src/myfuzz/scenario/boom_gpio_irq_verification.py` and `tests/local_harness/test_boom_irq_verification.py`. Existing authenticated source/profile/driver/probes/artifact stay frozen. Source-only implementation and fixture verification only; actual execution requires separate root GO.

Use existing factory/genome/program with 6000 scheduler steps and512 declared quiesce steps. No ISR-dependent pulse extension. Record all native commands/responses/READY and both lifecycle processes caused by the current constructor then begin_case reset. Record all GPIO parsed commands, native samples, exact Runner events, coherent raw/projections/checker, source routing/target receipts/ledger, RAM read observations, source+metadata origin and actual PID/close0. Retain errors and partial prefixes in exclusive gzip artifacts.

Positive criteria: actual external pin rise applied after real boot_ready; actual GPIO physical IRQ0→1 and source/pulse binding; exactly one pulse with end-start64, exactly64 measured CPU irq/meip high ticks at those declared ticks; actual ROB and CSR interrupt cause0x800000000000000b, handler evec0x80000400; actual ISR INTSTATUS reads1 then0 after initial pre-edge clear0, with exact router/source/D response linkage. Actual accepted CPU native RAM writes and final RAM cause/mepc/status1/cleared0/done1/resumed1 must agree. Exact MRET qualified by system_return1/cmd4/addr0x302, actual evec at MRET equals saved mepc, then actual foreground CSR PC and accepted resumed RAM store. CSR io_pc/evec are passive observations, not independent instruction retirement certification. No aggregate system-return, guessed expected PC or firmware-content-only evidence suffices.

Negative: keep actual GPIO source and fixed64 delivery policy; intercept CPU adapter input only in explicit controlled environment, record requested64 high ticks but offer0 to real native edges. Require all measured meip0, no interrupt cause/qualified MRET/ISR result stores/status read/done/resumed while real GPIO IRQ still occurred. This is an environment fault control, not a DUT defect. Runtime errors/unknown/partial prefixes are retained and cannot satisfy positive or negative success.

Two positive fresh runs must have distinct actual process/execution/stream identities, close0 and full raw, commands, runtime/source/GPIO/router/Runner/RAM prefixes equal after narrowly declared typed identity normalization. Never normalize arbitrary nested payload keys or data. Retain full originals and first actual difference.

Native entry must require explicit --run-native, new confined output, exact source freeze and reviewed metadata/binary pins before acquiring canonical nonblocking lock. No rebuild of the reused BOOM binary. Generic GPIO may compile only in the later authorized runtime entry; source-only/default/freeze/tests must not construct sessions, query tools or call subprocess. Host discovery scope surrounds whole gate. source_authority/new_cpp_build/full_P6 remain false; native IRQ observation pass is separate from generic admission.
